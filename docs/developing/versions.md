# Version overview

Every component has its own version file, listed in
[`scripts/version/components.json`](https://github.com/Developer-Simon/energy-node/blob/main/scripts/version/components.json).
A release tag carries the dashboard version. The tables below show which
version of each component a release contains, read from the version files at
that tag. They are generated during the site build by
`scripts/docs/release-versions.py`.

Components marked "Node bundle" ship in the signed bundle that the installer
and the dashboard updater put on the node. The installer and the Home
Assistant integrations are released on their own, so their versions at a tag
only tell you what was on `main` at that point.
