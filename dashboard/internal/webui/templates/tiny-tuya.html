TinyTuya einrichten

Vorbereitung und externe Abhängigkeiten
  1. Ein Konto auf der Tuya IoT Platform anlegen und ein Cloud-Projekt über Development → Create Cloud Project erstellen.
  2. Im Projekt das Datacenter passend zur Region der Tuya Smart- oder Smart-Life-App wählen, zum Beispiel Central Europe oder Western Europe.
  3. Die passende Smart Home-Trial-Subscription beziehungsweise API-Freigabe zum Projekt hinzufügen.
  4. Das Gerät im Cloud-Projekt über Link Devices by App Account mit dem verwendeten Tuya-Smart- oder Smart-Life-App-Konto verknüpfen.
  5. Im Projekt Access ID und Access Secret öffnen und hier eintragen. Das Secret kann mit der Speicheroption für spätere Abfragen im Dashboard-Datenverzeichnis abgelegt werden.

Die Zielinstallation benötigt außerdem TinyTuya auf GitHub beziehungsweise das TinyTuya-Paket auf PyPI. Falls ein Local Key nicht aus der Cloud-Liste kommt, muss er mit den TinyTuya-Werkzeugen auf dem Zielsystem ermittelt werden.

Local Keys ändern sich häufig, wenn ein Gerät in der App neu verknüpft wird. Nicht benötigte Zugangsdaten und Local Keys niemals in ein öffentliches Repository übernehmen.
